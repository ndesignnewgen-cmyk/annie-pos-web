ເລີ່ມຕົ້ນໃຊ້ງານ

ຕັ້ງຄ່າຮ້ານໃຫ້ພ້ອມຂາຍ ພາຍໃນ 3 ຂັ້ນຕອນ.

  1. ເຂົ້າສູ່ລະບົບ ດ້ວຍ ອີເມວ + ລະຫັດຜ່ານ ທີ່ໄດ້ຮັບ (ໃຊ້ໄດ້ໃນ ມືຖື · ຄອມ · ເວັບ ຂໍ້ມູນກົງກັນ).
  2. ເລືອກປະເພດຮ້ານ ຕອນສ້າງຮ້ານ (ອາຫານ / ກາເຟ / ລ້າງລົດ / ມືຖື …) → ໄດ້ໝວດສິນຄ້າมาให้เลย.
  3. ໄປ ☰ ເມນູ → ຕັ້ງຄ່າຮ້ານ → ໃສ່ ຊື່ຮ້ານ · ທີ່ຢູ່ · ເບີໂທ · ໂລໂກ້ · QR ຮັບເງິນ.
  4. ຕໍ່ ແລະ ຕັ້ງຄ່າ ເຄື່ອງພິມ (ເບິ່ງຫົວຂໍ້ 11).
💡
ຂໍ້ມູນเก็บใน Cloud — ปลอดภัย ไม่สูญ · เปิดได้หลายเครื่องพร้อมกัน ຂໍ້ມູນຕົງກັນ.

  2. ໃສ່ ຊື່ · ໝວດ · ລາຄາ · ຮູບ → ເລືອກຮູບແບບການຂາຍ:

ຂາຍ ແລະ ຄິດເງິນ

ຈິ້ມ → ຄິດເງິນ → ພິມບິນ ພາຍໃນ 5 ວິນາທີ.

  1. ກົດເມນູໃສ່ຕະກร้า (ກົດຊ້ຳ = ເພີ່ມຈຳນວນ · ລາຍການດຽວກັນ ຈະລວມเป็น 3x ບໍ່ແຍກบรรทัด).
  2. ກົດ ຄິດເງິນ → ເລືອກວິທີຊຳລະ:
💵 ເງິນສົດ📲 QR / ໂອນ 💳 ຕິດໜີ້ (ຂາຍເຊື່ອ)➗ ແຍກຈ່າຍ (ສົດ+ໂອນ) 💱 ຮັບเงินต่างประเทศ
  1. ໃສ່ ສ່ວນຫຼຸດ / ສະມາຊິກ (ຖ້າມີ) → ຢືนยัน → ພິມບິນ.
✏️
ອອກบิลไปแล้ว ແກ້ວິທีจ่ายได้ — ໄປ ລາຍງານຂາຍ → ແຕะบิล → "ວິທີຈ່າຍ" (ເช่น QR→เงินสด).

💰

ເປີດ / ປິດກະ (ນັບເງິນ)

ຮູ້ຍອດຂາຍທຸກມື້ · ກັນເງິນเสีย/เงินขาด · ກັນລູກນ້ອງໂກງ.

  1. ເປີດກະ: ☰ → ຈັດການກະ → ໃສ່ເງິນທອນเริ่มต้น → ເປີດ (ຕ້ອງເປີດກ່ອນຂາຍ).
  2. ປິດກະ: ກົດຈັດການກະ ອີກຄັ້ງ → ນັບໃບເງິນໃນລິ້ນຊັກ (100,000 ×… ) → ລະບົບບອກ ພໍດີ / ເກີນ / ຂາດ.
  3. ຫຼັງປິດກະ → ພິມ ໃບສະຫຼຸບກະ (Z-Report) ອັດຕะโนมัติ.
📜
ເບິ່ງຍ້ອນຫຼັງ: ☰ → ປະຫວັດກະ — ໃຜເປີດ/ປິດ · ຍອດຂາຍ · ເກີນ-ຂາດ · ພິມຊ້ຳໄດ້.

ລະບົບໂຕະ & ສັ່ງຜ່ານ QR

ຮ້ານອາຫານ — ເປີດບິນຄ້າງທີ່ໂຕะ ຈ່າຍທีหลัง.

ເປີດใช้: ຕັ້ງຄ່າຮ້ານ → ເປີດ 🍽️ ໃຊ້ລະບົບໂຕะ

  1. ພະນັກງານສັ່ງ: ເລືອกເມນູ → ສົ່ງເຂົ້າໂຕະ → ເລືອกເລກໂຕะ → ຄົວໄດ້ໃບเอง.
  2. ລູກຄ້າ QR: ສະແກນ QR ทีโต๊ะ → สั่งเอง → ອໍເດີเข้าอัตโนมัติ.
  3. ຄິດເງิน: ☰ → Monitor (ດຶງບິນ) → ແຕະໂຕะ → ຄິດเงิน.

ຍ້າຍໂຕะ

ແຕะໂຕะ → "ຍ້າຍໂຕະ" → เลือกโต๊ะใหม่

ແຕะໂຕะหลัก → "ລວມໂຕະ"

ແກ້/ລົບ ລາຍการ

ปุ่ม − / + / 🗑️ ต่อรายการ

ຈໍຄົວ (Kitchen)

ອໍເດີເด้งเข้าครัว → ทำเสร็จกด "ເสิร์ฟแล้ว".

  1. ☰ → ຈໍຄົວ → ເປີດຄ້າງไว้บนเครื่องในครัว.
  2. ອໍເດີໃໝ່ = ມີສຽง ding + ຂຶ້ນคอลัมน์ "ລໍຖ້າ".
  3. ເລກໂຕะ ໂຕໃຫຍ່ชัด ເທ່າໃບເຊັກບິນ.
  4. ເປີດ 🖨️ ມุมขวาบน = ພິມໃບຄົວອັດຕະໂນມັດ เมื่อออเดอร์เข้า.
🖨️
ຮ້ານເครื่องพิมพ์เดียว (ບໍ່เปิดจอครัว) → ຕັ້ງຄ່າ → "ພິມอໍเดอร์โต๊ะ/QR อัตโนมัติ" ໄດ້เหมือนกัน.

ຄັງ & ວັດຖຸດິບ/ສູດ

ນັບສະຕັອກ · ຮັບເຄື່ອງเข้า · ຫຼາຍເມນูตัดวัตถุดิบก้อนเดียวกัน.

ຄັງສິນຄ້າ: ☰ → ຄັງ → ຮັບເຄື່ອງเข้า · ນັບໃໝ່ · ຕັດຂອງเสีย · ເตือนใกล้หมด/หมดอายุ.

🥩 ວັດຖຸດິບร่วม (ຮ້ານອາຫານ/ເครื่องดื่ม):

  1. ☰ → ວັດຖຸດິບ (ຄັງຄົວ) → ເพิ่ม "ປາดิบ/ນົມ/ແກ້ວ" + ຈຳນວນ + ໜ່ວຍ (ໂຕ/ml/ກຣາມ).
  2. ແກ້ເມນູ → ສ່ວນ ສູດ → ເລືອกວັດຖຸດິບ + ຈຳนวนต่อจาน (ເครื่องดื่มใส่ M/L แยกได้).
  3. ຂາຍ → ຕັດວັດຖຸດິບໃຫ້ເອງ · ท็อปปิ้งก็ตัดของมันเอง.
📊
ໃນໜ້າວັດຖຸດິບ ກົດ 📊 → ເບิ่ง ວັດຖຸດิบใช้ไป + ต้นทุนต่อจาน (กำไร/จาน).

ສະມາຊິກ & ໂປຣໂມຊັ່ນ

ລູກຄ້າประจำ — ສະສົມແຕ້ม · ສ່ວນຫຼຸດ · ໂปรโมชั่น.

  1. ເພີ່ມສະມາຊິກ (ຊື່ + ເບີໂທ) → ตอนคิดเงินเลือกสมาชิก → ໄດ້ແຕ້ມอัตโนมัติ.
  2. ຕັ້ງ ໂປຣໂມຊັ่น (ຊື້ X ແຖມ Y / ຫຼຸດ %) → ໃຊ້ຕอนขายอัตโนมัติ.
  3. ຂາຍເชื่อ/ຕິດໜີ້ → บันทึกยอดค้าง · เก็บเงินภายหลัง.

Catalog — ລາຍการสินค้าตามยี่ห้อ

ຮ້ານໄອທີ/ມືຖື — ໂຊว์สินค้าแยกยี่ห้อ (acer/ASUS…) ໃຫ້ລູກຄ້າເບິ່ງ.

  1. ໃສ່ ຍີ່ຫໍ້ ໃຫ້ສินค้าไอที (ตอนแก้สินค้า → ช่อง Brand).

  3. ແຕะเมนู = ເพิ่มลงตะกร้าขาย · ปุ่ม ⬆️ = ສ่งออก PDF ส่งลูกค้า.

ເຄື່ອງພິມ (Bluetooth / USB / LAN)

ຮອງຮັບ ເครื่องพิมพ์ความร้อน 80mm/58mm ຄົບ 3 ແບບ.

📱 Bluetooth (ມືຖື)

ຈັບຄູ່ BT → ຕັ້ງຄ່າ → ເลือกเป็นเครื่องรับเงิน/ครัว → ตั้ง 80mm

🖥️ USB (ຄอมพิวเตอร์)

ຕໍ່ USB → ລົງໄดรເวີ → ຕັ້ງຄ່າ → การ์ด "ເครื่องพิมพ์ Windows" → ເລືອກເครื่อง → ທດสอบ

🌐 LAN / WiFi

ໃສ່ IP ຂອງเครื่องพิมพ์ + Port 9100 → ບັນທຶກ → ທดสอบ

⚠️
ໃຊ້ USB → ໃຫ້ລ້າງຊ່ອງ Network IP ອອກ (ຖ້າมีค้างไว้จะขัดกัน) · ໃบไม่ออก = เช็คว่าเลือกเครื่องถูก + ตั้ง 80mm.
